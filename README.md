## ⚡ Quick start

```bash
# 1. Clone any category you need
git clone https://github.com/afeezadebayo/technical-seo-skills.git

# 2. Drop a skill into your agent
cp -r technical-seo-skills/xml-sitemaps ~/.claude/skills/     # Claude Code
cp -r technical-seo-skills/xml-sitemaps ~/.agents/skills/     # OpenAI Codex

# 3. Start a session and ask your agent which skills it can use
```

For **Claude.ai / Desktop**, zip a skill folder and upload it under **Settings → Capabilities → Skills**.
To **bulk-load** a whole category into a Claude Project, custom GPT or knowledge base, grab the single-folder `.zip` from the [library page](https://afeezadebayo.com/skills-md/marketing/).
